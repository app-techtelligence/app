Mosaico — M1 spike

Measures whether this engine can do what the architecture assumes. Run every panel, then paste the results into spike/RESULTS.md. Run it in Edge on Windows — that is the engine WebView2 uses.

Results

1 · Environment

The WebGL context count decides the renderer-slot budget. The design assumes at least 6 usable contexts plus headroom. To test mixed-DPI, drag this window to a monitor with a different scale factor.

—

2 · Board — many live terminals at once

Real xterm.js instances, not mock-ups. Camera still is the honest test of the Live tier. Camera moving CSS-transforms the whole board, which the real app will not do for text — treat it as an upper bound on compositor headroom.

4 · Keyboard — dead keys, AltGr, IME

      ´+a → á (C3 A1),
      ~+a → ã (C3 A3),
      ç (C3 A7), and an AltGr combination.
      A dead key must produce nothing on its own, then one composed character.
